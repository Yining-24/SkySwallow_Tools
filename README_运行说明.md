# Tina 收汇明细与总表程序

一个年度明细 Excel 文件包含全部客户。每个客户使用一个独立明细 sheet，例如 `IBIS明细`、`RST明细`。

总表是另一个独立 Excel 文件。总表中每个客户各有一个 sheet，另有一个 `总体数据` sheet 集中放全部客户的数据。

## 第一次使用

把下面三个文件放在同一个文件夹：

- 年度 Excel 文件
- `tina_明细利润.py`
- `tina_生成总表.py`

Mac 终端第一次运行时安装依赖：

```bash
python3 -m pip install openpyxl
```

## 日常运行顺序

先关闭正在打开的 Excel 文件。

第一步，计算各客户明细中的每单毛利润和毛利率：

```bash
python3 tina_明细利润.py "/完整路径/2026_明细.xlsx"
```

该程序直接更新原 Excel，并先生成一份名字带 `_明细利润运行前备份` 的备份文件。每次运行都会备份，但使用同一个备份文件名，所以新一次运行会覆盖上一次备份，不会无限生成很多份。

第二步，需要刷新独立总表时运行：

```bash
python3 tina_生成总表.py "/完整路径/2026_明细.xlsx"
```

如果要同时生成客户 C/K 标记及提成试算，把 C/K 表作为第二个输入文件：

```bash
python3 tina_生成总表.py "/完整路径/明细.xlsx" "/完整路径/2027_客户归属_CK标记模板.xlsx"
```

C/K 表按你现在的简化格式填写：`客户名 / 标记 / 员工名`。标记只能是 C 或 K；客户名大小写不影响匹配。同一客户只保留一行。没有匹配客户或未填写员工名时，生成文件会明确提示。没有传 C/K 表时，仍按原来的格式生成总表。

该程序只读取各客户明细 sheet 已经算好的每单毛利润和毛利率，不会重新计算每单利润，也不会修改明细文件。它会在明细文件旁生成名字带 `_总表.xlsx` 的独立文件；再次运行时直接更新该总表文件。

如果希望指定总表文件名：

```bash
python3 tina_生成总表.py "/完整路径/2026_明细.xlsx" -o "/完整路径/2026_总表.xlsx"
```

生成的总表工作簿包括：

- `总体数据`：只列出各客户合计，底部另有一行所有客户合计
- 每个客户一个 sheet：该客户的逐单数据，底部列出客户合计
- 传入 C/K 表时，另有 `员工提成` sheet，按员工和自然年度汇总

提成栏是试算：C 类按每单毛利润的 5%，K 类按 10%；毛利率低于 10% 时再乘 `本单毛利率 ÷ 10%`，亏损单为 0。员工在 2027 年的毛利润合计为负时，年度规则后试算为 0。逐单试算金额先四舍五入到分，再汇总。K 类表里没有保护期起算日，所以程序不能验证 12 个月是否仍在保护期；2026 模拟数据只是套用 2027 制度演示，年度规则后金额留空。出货、收汇完成情况及制度要求的费用也尚未核实，不能把试算额当作应发额。

## 明细格式

每个订单按一个区块向下记录，表头固定为：

```text
客户名称 / 日期 / 记录类型 / 项目说明或对方 / 发票金额 / 收汇USD / 汇率 / 金额RMB / 开票金额 / 备注
```

发票号写在区块标题中，例如：

```text
发票号：INV-PENTAGON-2026-001
```

每票从表头到利润结果行都使用黑色边框。记录类型可以写：

- 收汇
- 实际货款
- 退税
- 运费、代理费、其他费用等支出名称

“发票金额”填写在 E 列，“开票金额”填写在 I 列；它们是两项独立数据，均不计入实际收支与毛利润。开票金额可填在对应的实际货款行。如果一个金额跨多行合并，程序只计算一次，不会重复汇总。

每个订单底部固定为两行：

```text
D列：发票金额合计 / E列：程序填写发票金额合计 / G列：本单毛利润 / H列：程序填写金额 / I列：程序填写开票金额合计 / J列：开票金额合计
G列：本单毛利率 / H列：程序填写比例
```

同一票有多笔发票金额或开票金额时，程序分别加总；合并的金额单元格只计算一次。某一列没有填写金额时，该列合计保持空白，不会填 0。总表不新增“发票金额”，仍只读取原有的开票金额等字段。

金额正负号规则：收汇和退税填写正数；实际货款、运费、代理费和其他支出属于转出，必须填写负数。

日期及其他缺失内容可以留空，程序不会编造数值。终端会显示具体空白单元格；无法完整计算的汇总字段保持空白。

数字可以是人工输入值，也可以是 Excel 公式。程序会先读取 Excel 保存的计算结果；如果公式缓存为空，还会尝试计算常见的加减乘除、`SUM`、`ROUND` 和 `ABS`。遇到更复杂且没有保存结果的公式时，先用 Excel 打开文件、完成计算并保存，再运行程序。

## 利润口径

```text
每单毛利润 = 收汇RMB + 表内退税金额 + 实际货款（负数）+ 其他支出（负数）
每单毛利率 = 每单毛利润 ÷（收汇RMB + 总退税）
```

退税直接使用“金额RMB”列中记录的金额。程序不会根据备注中的 `13%` 再乘一次。

总表中的每单利润和利润率直接取自客户明细。客户总利润为各单利润之和；客户总毛利率使用客户总利润除以客户总收汇RMB与总退税之和。

## 总表表头

`总体数据` sheet 不显示日期：

```text
客户名称 / 收汇USD / 汇率 / 收汇RMB / 开票金额 / 实际货款 / 总退税 / 总毛利润 / 平均毛利率
```

每个客户自己的 sheet 保留每票收汇日期：

```text
客户名称 / 日期 / 收汇USD / 汇率 / 收汇RMB / 开票金额 / 实际货款 / 总退税 / 每单毛利润 / 每单毛利率
```

独立总表不再显示发票号列。发票号只保留在明细每票的标题中。

`总体数据`的总毛利润是各单毛利润之和；平均毛利率按“总毛利润 ÷（总收汇RMB＋总退税）”计算，是按金额加权的平均，不是各单毛利率的简单算术平均。传入 C/K 表时，`总体数据`和客户分表显示员工姓名、客户类别、提成试算RMB；各个 sheet 都不显示提成状态。客户未匹配、数据缺失及 K 类保护期未核实等情况会在终端提示，不能把试算金额视为应发额。
